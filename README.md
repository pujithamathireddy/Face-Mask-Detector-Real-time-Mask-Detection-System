# Face-Mask-Detector – Real-Time Mask Detection System

## Project Overview

Face-Mask-Detector is a real-time computer vision project that detects whether a person is wearing a face mask using a webcam. The system uses a deep learning model to classify detected faces into **With Mask** and **Without Mask** categories.

## Key Features

* Real-time face mask detection using a webcam.
* Classifies faces as **With Mask** or **Without Mask**.
* Uses OpenCV for image and video processing.
* Uses TensorFlow/Keras with MobileNetV2 for image classification.

## Technologies Used

* Python
* OpenCV
* TensorFlow / Keras
* MobileNetV2
